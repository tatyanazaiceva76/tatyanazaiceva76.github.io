What this calculator does

This planner moves forward from a rate you already know. Daily pulls are multiplied by the remaining days, while the weekly bonus is counted only for complete seven-day blocks. Both gains are added to the starting balance.

Keeping daily and weekly income separate prevents a common double-counting mistake. If your daily average already includes weekly rewards, leave the weekly bonus at zero. If income varies, use a conservative average and rerun an optimistic scenario separately.

The result is a budget projection, not a banner outcome. It does not apply pity, drop rates, or featured-unit rules; use a probability calculator after finding the projected pull total.

Formula

final budget = saved + daily rate × days + weekly bonus × floor(days ÷ 7)

Example: With 25 saved pulls, 1.5 per day, 21 days, and 5 per full week, the plan earns 46.5 pulls and reaches a projected budget of 71.5.

FAQ

Why are partial weeks ignored?

The weekly input represents a reward received once per complete seven-day block; daily earnings still count every day.

Can I model two scenarios?

Yes. Run the calculator with separate conservative and optimistic daily averages and compare the final budgets.

Does the result include my current pity?

No. It projects pull inventory only; counter state is handled by the pity-remaining tool.
