How these calculators differ from game-specific pity models

The tools in this section do not embed a publisher rule, community soft-pity curve, banner schedule, reward forecast, or currency pack. They answer narrower mathematical questions from user-supplied inputs. That makes each result easy to reproduce and keeps a rule update in one game from silently changing an unrelated calculation.

Inventory tools convert or project pull counts. Counter tools measure distance to a cap you provide. Probability tools explicitly state when they assume a constant rate and independent attempts. If the scenario has changing rates or guarantee states, use a documented game-specific model instead of forcing those rules into a fixed-rate formula.

Results describe the entered scenario, not what anyone should spend or which banner to choose. Check units before comparing outputs, keep target definitions consistent, and rerun the calculator whenever an input changes.
